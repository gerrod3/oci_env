# lean

Density-focused profile for parallel or short-lived Pulp environments.

See the profile README (`oci-env profile docs lean`) and the
[agent environments guide](../../guides/agent-envs.md).

## Defaults

| Variable | Default |
|----------|---------|
| `PULP_WORKERS` | `1` |
| `LEAN_MEM_LIMIT` | `2g` |
| `LEAN_CPUS` | `1.0` |
